# Influencer Echo

I would like to create an app that takes social media influencers' products that they're currently selling, the top ones, ingest the idea, replicate it, create a brand new video with a influencer style video that I can then repost on TikTok, Reels, and effectively do affiliate marketing on products without any personal video creation myself. The app would actually ingest the product, identify the affiliate marketing payment program, recognize how to get paid, and have a direct link for me to get paid, and have the app effectively then create a video, a 15-second social media influencer video that I can post on TikTok, affiliate marketing the same product that I can ship without ever having to handle or hold any products, and have this be a workadle- workable app that I can utilize in my own environment.
